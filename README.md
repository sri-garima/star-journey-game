# 🚀 Star Journey – A Child’s Space Dream

A cartoon-style zero-gravity space adventure game for children built using Phaser.js.

## 🌌 About The Game

What if a child sitting on a terrace one night could actually float into space and explore the universe?

“Star Journey” is a dreamy, kid-friendly game where a child slowly drifts from their terrace into a magical cosmic world filled with stars, planets, galaxies, and wonder.

The mission begins in space:
⭐ Collect stars  
☄️ Avoid obstacles  
🚀 Explore the universe in zero gravity

# 🎮 Features

- 🌌 Zero-gravity movement mechanics
